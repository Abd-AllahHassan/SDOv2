# SDOv2

Official production landing page for Specialized Dental & Orthodontic Center (SDO Center), Abu Dhabi.

## Features
- Complete luxury design matching `preview.html`
- Fully responsive (desktop flex-accordion & mobile touch-slider)
- 10 Specialized Clinical Suites with bespoke 3D Holographic SVG illustrations
- Interactive Before & After comparison slider
- Bilingual English & Arabic with dynamic RTL layout & Cairo typography
- Integrated Production Booking modal with WhatsApp coordination
- Ready for immediate Vercel deployment with zero build configuration
